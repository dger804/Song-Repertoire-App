# Shared Package

Paquete reservado para tipos y utilidades compartidas entre frontend y backend.

## Responsabilidad

- Alojar tipos TypeScript compartidos cuando exista una necesidad real.
- Evitar duplicacion de contratos simples entre `apps/web` y `apps/api`.

## Regla importante

No agregar abstracciones prematuras. Este paquete debe permanecer pequeno y solo crecer cuando reduzca duplicacion real.
